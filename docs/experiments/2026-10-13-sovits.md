# 心铃TTS：SoVITS 10轮与20轮比较

用户已认可10轮SoVITS / 5轮GPT的效果，尤其喜欢日语口音。本次按用户要求直接在终端续训SoVITS，GPT固定5轮；不使用Jupyter执行这次训练。

## 训练与控制变量

- 原64条校对日语、同一份特征、batch2、半精度和梯度检查点。
- 从SoVITS10轮G/D及优化器状态恢复，训练第11–20轮；20轮推理模型为 `models/misuzu_gsv_v2pro_v1/sovits/misuzu_gsv_v2pro_v1_e20_s1280.pth`。
- 旧10轮推理模型及试听保留，GPT仍使用 `gpt/misuzu_gsv_v2pro_v1-e5.ckpt`，没有额外训练GPT。
- 参考片段 `fem_mis_00025_000.wav` 和已校对日语台词相同；文本、语言、seed=20261012、temperature=1、top_k=15、top_p=1、speed=1、batch1与原试听一致。
- 每个版本独立统一-22 LUFS、48kHz、单声道PCM16。只比较音色、自然度、中文清晰度及口音，不以更多轮数直接认定更好。

## 试听

结果目录：`outputs/misuzu_gsv_v2pro_v1/comparison_s10_s20_g5/`。

每条播放顺序：**SoVITS10轮/GPT5轮 → 1秒静音 → SoVITS20轮/GPT5轮**。

- 中文日常：`zh_daily_10_then_20.wav`，今天的天气很好。要不要一起出去走走？
- 中文疑问：`zh_question_10_then_20.wav`，你真的觉得，这样就可以了吗？
- 日语日常：`ja_daily_10_then_20.wav`，今日はいい天気ですね。少し散歩しませんか？

`normalized/`保留两组独立统一响度的音频，`manifest.json`记录模型哈希、参考音频哈希、原始音频哈希、文本和各段时间位置。原始20/5样音在 `samples_s20_g5/`；10/5在 `samples_s10_g5/`。旧10/5的purpose字段写成one-epoch是旧脚本的通用说明错误，实际权重路径明确为10/5；本次脚本已修正并额外记录轮数与推理控制参数。

## 重现

```powershell
python scripts/tts_finetune.py train-sovits --epochs 20
python scripts/tts_sample.py --sovits-epoch 20 --gpt-epoch 5
python scripts/compare_tts_checkpoints.py --first 10 --second 20 --gpt 5
```

训练完整日志在 `runs/misuzu_gsv_v2pro_v1/logs/continue_sovits_20e.log` 与同目录对应train_sovits阶段日志；推理日志为 `sample_s20_g5.log`。该实验完成时配置仍为10/5，之后已选择20/10为当前默认。
