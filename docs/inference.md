# 本地TTS推理界面

GPT-SoVITS自带Gradio网页界面。本地启动入口 `scripts/tts_webui.py` 使用同一独立环境与TTS引擎，当前默认心铃SoVITS20/GPT10，记住每个任务的成功模型选择；在上游快速推理UI加入任意数量角色和训练任务管理，不运行训练。

顶部选角色和训练任务，下方选两份权重，再点击“加载所选模型”。参考信息按任务恢复；未训练任务不能合成。展开管理区可以登记新角色、创建新任务、上传原素材、导入配套模型及保存参考。详细目录和训练命令见 [多角色管理](characters.md)。

```powershell
Set-Location D:\Project\voice
& .\vendor\GPT-SoVITS\.venv\Scripts\python.exe scripts\tts_webui.py
```

直接双击根目录 `Start-Inference.cmd`，浏览器地址 `http://127.0.0.1:9872`。`Start-WebUI.cmd`打开官方主界面 `http://127.0.0.1:9874`。本次两页HTTP200，快速推理API实际生成了1.7秒有效中文音频，确认加载20/10。

终端Ctrl+C停止，或双击 `Stop-WebUI.cmd` 停止本项目启动的界面进程树。后台验证时服务窗口隐藏；本次已保持服务运行供操作。仅监听127.0.0.1，share=False。

当前推理服务已经开启，直接打开9872即可调参和生成；主界面不必再次点“开启TTS推理WebUI”。后续从主界面自行启动推理时，先用Stop-WebUI关闭本次后台服务，再只启动Start-WebUI。

`--check`只检查文件路径；`--mode main`启动主界面；也可用 `--sovits-epoch 20 --gpt-epoch 5 --port 9872` 选择已有模型和端口。首次设置参考后，生成结果可用播放器右上角下载按钮保存；官方界面临时缓存不等于自动保存到outputs目录，需要手动保存需要保留的结果。

## 参考与输入

- 默认参考音频已填入：`data/datasets/misuzu_gsv_v2pro_v1/wavs/fem_mis_00025_000.wav`。
- 参考语种：日文；参考台词：`校長先生からは許可書を頂いてますが`。
- 目标语种：中文；粘贴需要生成的文稿，点击合成语音。输出播放器可试听、下载。
- 不选无参考文本模式。替换参考时，台词须与音频一致；参考内容和语气也会影响结果。

## 参数起点

| 参数 | 含义 | 调整起点 |
|---|---|---|
| 语速 | 当前请求的语速，低于1更慢、高于1更快 | 1；过快句试0.85–0.95，过慢句试1.05–1.15 |
| 怎么切 | 决定每段的上下文长度与切点 | 长文先试中文句号切；问题句单独输入，避免过碎 |
| 分段间隔 | 生成片段间插入的静音，不能直接控制句内任意词后的停顿 | 0.3秒，按试听调整 |
| temperature | 采样温度，改变生成随机性，不是情绪强度 | 当前1；可对比0.8或0.9 |
| top_k | 每一步保留的候选token数量 | 当前15；初期保持 |
| top_p | 按累计概率保留候选范围 | 当前1；初期保持 |
| 随机种子 | 控制随机采样，方便参数对照或生成候选 | 默认20261012、保持随机关闭；找候选时换种子 |
| 重复惩罚 | 抑制重复token，过高也可能影响正常发音 | 当前默认1.35；出现重复再调整 |
| batch_size | 同时推理的片段数，影响吞吐、显存及随机采样路径 | 本地默认1；批量提高前观察显存 |

界面快速版固定parallel_infer=True，之前脚本使用False；即使模型和采样参数相同，也不承诺与旧试听逐样本一致。严格受控对照仍用脚本记录参数。

Euler steps、CFG与超采样等选项主要属于其他模型版本，不作为本次v2Pro调节重点。界面没有可直接指定某个词重音或整段每一句独立语速的编辑轨道；局部修改应分句生成再拼接。推理参数调整不需要重新训练。
